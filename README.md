# بوابة رعاية الأسرة — الإصدار 4

بوابة عربية RTL تعمل كواجهة ثابتة ويمكن نشرها على GitHub Pages دون خادم خلفي.

## محتويات الإصدار
- النماذج الستة الأصلية: الملف الشخصي، التموين والمنزل، الصحة، الزيارات الاجتماعية، الثقافة، والتعليم.
- مركز استبيانات موسع يشمل: استبيان عام، احتياجات الأسرة، رضا المستفيدين، التوعية الصحية، التعليم والتدريب، التطوع، تقييم الفعاليات، المهارات والتوظيف، السكن والصيانة، التموين، الثقافة والترفيه، الوصول الرقمي، أولويات المجتمع، الملاحظات والشكاوى.
- حقول متنوعة: نص، رقم، تاريخ، قائمة، اختيار متعدد، اختيار واحد، تقييم من 1 إلى 5، وملاحظات مطولة.
- تصدير إجابات الاستبيان إلى JSON وCSV (يمكن فتح CSV في Excel) وTXT.
- إنشاء ملف HTML تفاعلي مستقل للنموذج، يمكن فتحه في متصفح حديث دون خادم، ويحتوي على تنزيل JSON/CSV ومشاركة الملخص عبر واتساب.
- رسائل واتساب منظمة باللغة العربية.
- تصميم متجاوب، واتجاه RTL، ومظهر فاتح/داكن.

## تشغيل ونشر
1. فك ضغط الملف.
2. افتح `index.html` في متصفح حديث لمعاينة الموقع. يلزم اتصال بالإنترنت لبعض مكتبات التصدير والخطوط الخارجية في النماذج الأصلية.
3. للنشر: ارفع ملفات المجلد إلى مستودع GitHub، ثم من Settings → Pages اختر الفرع ومجلد الجذر.

## مشاركة الملفات عبر واتساب
- زر مشاركة واتساب يفتح رسالة نصية جاهزة؛ يجب مراجعتها والضغط على إرسال داخل واتساب.
- زر HTML ينشئ ملف نموذج تفاعلي مستقل؛ نزّل الملف ثم أرفقه يدوياً في محادثة واتساب كـ Document.
- CSV هو ملف جدولي يفتح في Excel، وJSON مناسب لنقل البيانات بين التطبيقات، وTXT نصي بسيط.
- لا يستطيع موقع GitHub Pages الثابت إرفاق ملف تلقائياً إلى واتساب أو إرسال الرسائل في الخلفية. الإرسال الفعلي يحتاج إجراءً من المستخدم أو خادماً وتكامل API مناسباً.

## الخصوصية والحدود
- لا توجد قاعدة بيانات أو حسابات مستخدمين في هذا الإصدار.
- الإجابات التي يتم تصديرها تُنزّل على جهاز المستخدم؛ لا تُرفع إلى خادم من هذا الموقع.
- تجنب إدخال كلمات المرور أو أرقام الهوية أو التفاصيل الصحية شديدة الحساسية في الاستبيانات العامة.
- ملفات HTML التفاعلية مناسبة لتعبئة النموذج في المتصفح، لكن جمع ردود عدة أشخاص مركزياً يحتاج Backend أو خدمة نماذج خارجية.
